DesignForYou

DesignForYou helps you describe a home project in simple steps and see a draft of it in 3D. It needs no login, and nothing you enter leaves your browser.

The design team is a set of fixed rules, not AI. It does not look at your images or read your brief.

Nothing is saved. If you close or reload this page, everything you entered is lost.

Set up your project

Name your project, then add its floors and rooms. Nothing is saved: if you close or reload this page, what you entered is lost.

Still needed before you can run the design team: a project name, a floor and a room.

Project name

Up to 60 characters.

Add a floor

For example "Ground floor". A project has 1 to 4 floors.

Add a room

Add a floor first. Then choose it here.

For example "Kitchen". Up to 20 rooms in total. Each room needs a different name.

Width and depth are optional. They are only used to draw the 3D view. They are not the real size of your home. If you leave them as 4, the room is drawn 4 metres by 4 metres.
