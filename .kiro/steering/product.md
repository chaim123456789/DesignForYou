# DesignForYou: Product

## What it is
A browser web app for people with good taste who cannot use CAD software. Homeowners come first. Designers come second.

## How a user works with it
1. Upload up to 50 inspiration images.
2. Write a short brief.
3. Mark each item as **Locked** (must stay as is) or **Unsure** (open to change).

## Inspiration in layers
1. Overall style comes first and applies to the whole project.
2. Optional overrides can be added per room.

## The four agents
All agents work on one shared **Project Brain** (the single shared record of the project). A **Coordinator** runs them in this fixed order:
1. Style
2. Layout
3. Builder
4. Reviewer

## Rules
- One owner per item. Each agent owns separate files and items, so agents never edit the same thing.
- Locked items can never be overwritten by any agent.
- The Reviewer checks for clashes.
- Version history is kept for every change.

## Output
- A floor plan
- A 3D view
- A door and window list
- A clash report

## Safety statement
Plans are drafts for professional review. They are never claimed as verified engineering. Every output must say so.
